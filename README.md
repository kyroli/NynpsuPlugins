# NynpsuPlugins

Personal Dalamud plugin repository.

## 订阅链接

在 Dalamud 设置中的自定义插件仓库添加以下链接：

```text
https://raw.githubusercontent.com/kyroli/NynpsuPlugins/main/pluginmaster.json
```

加速镜像：

```text
https://fastly.jsdelivr.net/gh/kyroli/NynpsuPlugins@main/pluginmaster.json
```

## 插件列表

- **A Realm Recorded Lite**：副本录像回放与控制工具，修复包含大量剧情过场的长副本录像在快进时偶发内存异常崩溃的问题。
